# 눈싸움 1대1

친구에게 링크를 보내 들어오면, 위에서 비스듬히 내려다보는 쿼터뷰로 1대1 눈싸움을 해서 3판 2선승으로 승부를 내는 PC 웹게임입니다.

지금은 **2단계 전 버전(v0.2)** 으로, 컴퓨터 상대와 붙는 연습 모드까지 들어가 있습니다. 온라인 대전은 다음 단계에서 붙입니다.

## 실행

```bash
npm install
npm run dev          # 개발 서버
npm run build        # dist/ 배포용
npm run build:single # dist-single/index.html 한 파일짜리 미리보기
```

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 (중앙선은 못 넘음) |
| 마우스 | 조준 |
| Space 또는 우클릭 꾹 | 멈춰서 눈 뭉치기, 최대 3개 |
| 좌클릭 누르고 떼기 | 차지 던지기, 오래 누를수록 멀리 |
| Shift | 대시 (쿨타임 2초) |
| Esc | 일시정지 |

## 규칙

- HP 3, 세 번 맞으면 라운드 패배, 먼저 2라운드를 이기면 승리
- 눈 하나 뭉치는 데 0.8초, 뭉치는 동안은 못 움직이고 몸이 낮아짐
- 차지 0~1초에 따라 사거리 8m~20m, 차지 중엔 이동 속도 절반
- 눈벽은 두 번 맞으면 무너짐 (첫 방에 윗단, 두 번째에 아랫단)
- 숫자는 게임 안 설정 패널에서 바로 바꿔 볼 수 있음

## 구조

```
src/
  main.js       게임 흐름(카운트다운, 라운드, 결과), 루프, 화면 버튼
  config.js     조절 가능한 값과 고정 규칙
  fighter.js    플레이어 한 명의 상태와 행동 (intent를 받아 움직임)
  character.js  로우폴리 캐릭터 모델과 절차적 애니메이션
  input.js      키보드/마우스 → intent
  ai.js         연습 상대 → intent (난이도 3단계)
  snowballs.js  눈덩이 궤적과 충돌
  walls.js      눈 벽돌 벽, 파괴 파편
  effects.js    파편, 발자국, 화면 흔들림, 히트 스톱, 슬로모션, 카메라
  world.js      경기장, 조명, 배경 소품, 내리는 눈
  audio.js      Web Audio 합성 효과음
  hud.js        점수판, 탄약, 차지, 배너
```

플레이어는 키보드든 AI든 같은 `intent`(`{ mx, mz, aim, pack, charge, dash }`)만 넘겨주면 움직입니다. 온라인 단계에서는 상대 쪽 intent를 네트워크에서 받아 넣는 방식으로 붙일 예정입니다.
