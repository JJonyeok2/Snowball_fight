# 눈싸움

친구에게 링크를 보내 들어오면, 위에서 비스듬히 내려다보는 쿼터뷰로 눈싸움을 하는 PC 웹게임입니다. 1대1과 2대2를 지원하고, 각자 자기 컴퓨터에서 온라인으로 붙습니다. 혼자서는 컴퓨터 상대와 연습할 수 있어요.

## 실행

```bash
npm install
npm run build && npm start   # http://localhost:8080 (서버가 게임 화면도 같이 제공)
```

개발할 때는 터미널 두 개로:

```bash
npm run server   # 게임 서버 (8080)
npm run dev      # 화면 개발 서버, /ws 는 8080으로 넘겨줌
```

`npm run build:single` 은 연습 모드만 되는 한 파일짜리 미리보기를 `dist-single/` 에 만듭니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 (중앙선은 못 넘음) |
| 마우스, 또는 ← → | 조준 (방향키를 누르면 방향키 조준, 마우스를 움직이면 다시 마우스) |
| 좌클릭 또는 ↑ 누르고 떼기 | 차지 던지기, 오래 누를수록 멀리 |
| Space, 우클릭, ↓ 꾹 | 멈춰서 눈 뭉치기, 최대 3개 |
| 차지 중 Q, 우클릭, Space, ↓ | 차지 취소 (눈덩이는 그대로) |
| Shift | 대시 (쿨타임 2초) |
| Esc | 일시정지 (연습 모드) |

파랑팀은 화면이 뒤집혀서 항상 내 진영이 아래에 보입니다.

## 규칙

| | 1대1 | 2대2 |
| --- | --- | --- |
| 경기장 | 30 × 20m, 눈벽 6개 | 36 × 22m, 눈벽 10개 |
| 라운드 승리 | 상대를 한 번 쓰러뜨리기 (HP 3) | 먼저 5번 쓰러뜨리기 |
| 쓰러지면 | 라운드 끝 | 3초 뒤 출발 위치에서 부활, 1.5초 무적 |
| 경기 | 3판 2선승 | 3판 2선승 |

- 같은 팀이 던진 눈은 몸을 통과합니다.
- 눈 하나 뭉치는 데 0.8초, 뭉치는 동안은 못 움직이고 몸이 낮아집니다.
- 차지 0~1초에 따라 사거리 8~20m, 차지 중엔 이동 속도 절반.
- 눈벽은 두 번 맞으면 무너집니다 (첫 방에 윗단, 두 번째에 아랫단).

### 아이템: 얼음돌

- 라운드 시작 6초 뒤부터 10초마다 하늘에서 떨어집니다. 양 진영에 번갈아, 최대 2개까지 깔리고 15초 안에 안 주우면 사라집니다.
- 떨어지기 1.2초 전부터 바닥에 착지 표시가 깜빡입니다.
- 밟으면 얼음돌 2발을 얻고, 다음 던지기가 얼음돌로 바뀝니다.
- 얼음돌은 차지 없이 누르는 즉시 직선으로 날아갑니다 (초속 28m, 사거리 22m, 피해 1). 높이가 낮아 눈벽에 막힙니다.

## 온라인 방

1. 메뉴에서 이름을 적고 인원(1대1, 2대2)을 골라 **방 만들기**
2. **초대 링크 복사**로 친구에게 보내기 (또는 4자리 방 코드). 링크로 들어온 친구는 이름만 적고 바로 입장하는 화면을 봅니다.
3. 빈자리는 방장이 **AI 넣기**로 채울 수 있음
4. 방장이 **시작하기**

게임 중에 나간 사람 자리는 AI가 이어받고, 경기가 끝나면 다시 방으로 돌아옵니다.

## 구조

```
shared/            서버와 브라우저가 같이 쓰는 코드
  rules.js         모드별 경기장, 규칙 수치
  sim.js           게임 규칙 전체 (이동, 뭉치기, 던지기, 충돌, 부활, 라운드)
  ai.js            컴퓨터 플레이어
server/index.js    방 코드, 로비, 30Hz 서버 판정, 스냅샷 전송, 정적 파일 제공
src/
  main.js          메뉴, 로비, 화면 전환, 루프
  session-local.js 연습 모드: 브라우저에서 sim 직접 실행
  session-online.js 온라인: 내 캐릭터 예측과 보정, 다른 사람 보간
  net.js           WebSocket 연결
  input.js         키보드/마우스 → 입력
  hud.js           점수판, 내 상태, 배너, 킬 피드
  view/            Three.js 그리기 (경기장, 캐릭터, 벽, 눈덩이, 효과, 소리)
```

플레이어는 키보드든 AI든 네트워크든 같은 입력 `{ mx, mz, ax, az, pack, charge, dash }` 만 넘겨주면 움직입니다.

### 온라인 동기화

- 서버가 30Hz로 sim을 돌리고, 맞았는지는 서버가 판정합니다.
- 내 캐릭터는 입력을 보내는 동시에 같은 sim 코드로 먼저 움직이고, 서버 상태가 오면 아직 처리 안 된 입력을 다시 적용해 맞춥니다.
- 다른 사람과 눈덩이는 서버 시간 기준 0.1초 전 모습을 스냅샷 사이에서 보간해 그립니다.

## 배포 (Render 무료)

저장소의 `render.yaml` 로 Render 웹 서비스 하나에 서버와 화면이 같이 올라갑니다. 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다음 접속 때 깨어나는 데 1분 정도 걸립니다.
